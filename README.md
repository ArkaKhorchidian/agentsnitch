# agentsnitch

**What did your AI coding agents actually do?** agentsnitch reads the session logs that Claude Code, Codex and Gemini CLI keep on your machine and shows every command they ran and every file they touched. The ones worth a second look are flagged: force-pushes, `curl | sh`, reads of your SSH keys and `.env` files, and writes outside the project.

```bash
uvx agentsnitch
```

You approve commands one at a time, or you turned on auto-approve weeks ago. Either way, nobody reads the transcript afterwards. agentsnitch does.

## What it flags

| | Examples |
|---|---|
| **Remote code** | `curl … \| sh`, `wget … \| bash`, `iwr … \| iex`, `eval $(curl …)` |
| **Destruction** | `rm -rf ~/`, `git push --force`, `git reset --hard`, `DROP TABLE`, `terraform destroy`, `kubectl delete`, `aws s3 rm` |
| **Secrets** | private SSH keys, `~/.aws/credentials` and other cloud credentials, `.env` files, the macOS keychain / `pass` / 1Password CLI, `gh auth token`, dumping the whole environment |
| **Data leaving** | `curl -X POST -d @file`, `scp`/`rsync` to other machines, `nc` |
| **Shipping** | `npm publish`, `twine upload`, `docker push`, `gh release create`, `gh pr merge`, deploys |
| **Your system** | `sudo`, edits to `.zshrc`/`.bashrc`, cron jobs and launch agents, files written outside the project folder |

Text that's only *inside* a script (a heredoc, `python -c "…"`) isn't counted as run. `bash -c "…"` is, because that is shell.

## Where it reads

| Agent | Logs |
|---|---|
| Claude Code | `~/.claude/projects/*/*.jsonl` (or `$CLAUDE_CONFIG_DIR`) |
| Codex CLI | `~/.codex/sessions/**/rollout-*.jsonl` (or `$CODEX_HOME`) |
| Gemini CLI | `~/.gemini/tmp/*/chats/session-*` |

Cursor keeps its history in a SQLite database, which isn't supported yet.

## Options

```
agentsnitch                     # last 30 days
agentsnitch --since 7d          # or 12h, 2026-10-01, all
agentsnitch --project storefront
agentsnitch --agent codex
agentsnitch --low               # also show low-severity things (git push, rm -rf in the project, installs)
agentsnitch --log               # every command and file action, oldest first
agentsnitch --json              # for scripts
```

## Privacy

agentsnitch only reads files on your machine and sends nothing anywhere.

## Install

```bash
uvx agentsnitch           # run without installing
pipx install agentsnitch  # or install it
```

Requires Python 3.9+. The only dependency is `rich`.
